# Constraints

## Restricciones

### CON-001 — Limitacion de hardware

**Categoría:**  
Técnica

**Restricción:**  
El sistema debe funcionar con el hardware actualmente disponible que no permite modificaciones masivas.

**Impacto:**  
Los tiempos de desarrollo se extienden y limita el alcance de nuevas oportinudades tecnicas.

---

### CON-002 — Presupuesto limitado para software

**Categoría:**  
Economica

**Restricción:**  
No se cuenta con un presupuesto ni un fondo fijo para el desarrollo de herramientas de software por lo que cualquier intension de desarrollo debe ser por propuesta.

**Impacto:**  
La implementacion de soluciones son intermitentes y sin un flujo constante

### CON-003 — Equipo pequeño

**Categoría:**  
Operativa

**Restricción:**  
Por el momento solo se cuenta con un equipo reducido.

**Impacto:**  
Esto aumenta la carga de trabajo y los tiempos de desarrollo.

### CON-004 — Acceso remoto depende de arquitecturas externas

**Categoría:**  
Tecnica

**Restricción:**  
La consulta de informacion depende de distintos sistemas externos.

**Impacto:**  
Aumenta el riesgo de errores por actualizaciones o incompatibilidades.

### CON-005 — No se puede modificar directamente sistemas externos

**Categoría:**  
Operativa

**Restricción:**  
Muchos de los tramites y operaciones que se realizan son realizados desde sistemas externos proporcionados por la aseguradora, el corporativo o las instituciones financieras.

**Impacto:**  
Limita el rango de funciones que pueda tener el sistema.

### CON-006 — El proceso de consulta puede ser variable

**Categoría:**  
Tecnica

**Restricción:**  
No todas las aseguradoras funcionan de la misma manera al entregar informacion.

**Impacto:**  
Puede requerir crearse varias funciones para una misma operacion.
